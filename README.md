# 深渊回响：末环
**Abyss Echo: RingFall** · v1.0

一个**单文件 HTML 地牢爬行游戏**——双击即玩，无需安装、无需联网、无任何依赖。
支持 1~4 人本地同屏（热座）合作闯关。

---

## 快速开始

1. 双击 **`index.html`**（或拖进任意现代浏览器：Chrome / Edge / Firefox / Safari）。
2. 选择模式（单人 / 多人）、人数与初始生命。
3. 点「开始冒险」。

> 全部逻辑与美术都在这一个 HTML 文件里，拷到 U 盘、发微信、传网盘都能直接玩。

### 在线游玩（GitHub Pages）

仓库根目录已经放好 `index.html`，进入 **Settings → Pages**，Source 选 `Deploy from a branch`、分支选 `main` / 目录 `/ (root)`，保存后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可在线玩。

## 玩法目标

探索随机生成的地牢，逐层下潜，击败每层首领（BOSS）。第 1~3 层为常规层，
击败第 3 层首领后可选择带着荣誉通关，或继续**无尽模式**下潜——怪物会越来越强。

## 基本操作

| 操作 | 方式 |
|---|---|
| 移动 | 点击地图上的发光格（每回合最多 2 格） |
| 攻击 | 点击射程内的敌人，或「攻击」按钮（列表里队友标注「（队友）」，可用来帮队友解【蓝】/【白】） |
| 切换武器 | 点击自己卡片上的武器标签（青框可点，仅自己回合、且还有行动点时）——不占行动点，但会打断蓄力 |
| 开箱 / 给予 / 丢弃 / 道具 / 附魔 / 刻印主动技 | 左侧行动按钮 |
| 楼梯 | 走到楼梯相邻格后点击楼梯格 |
| 结束回合 | 「结束回合」按钮 |
| 怪物图鉴 | 点击顶部「📖 怪物图鉴」，查看全部怪物属性与技能（Esc 关闭） |

每人每回合 **2 点行动点**；移动、攻击、开箱、给予、道具等消耗 1 点，
丢弃、附魔（限 1 次）、商店交易不占行动点。

## 核心规则速查

- **房间**：每层 5×4 网格上随机生长 8~16 个房间——战斗 / 精英（每层保底 1 个）/ 宝藏 / 商店（每层保底 1 个）/ 祭坛 / 首领。入口房固定有「人数 + 1」个补给宝箱（上限 6）。
- **精英怪**：👹 兽人（狂怒 / 碎裂重击）· 🔮 渊火咒术师（咒火洗礼 + 后跳 + 受击瞬移）· 🩸 噬盾吞噬者（截胡护盾 / 碾碎【尘】/ 荆棘反噬 ≥15 反弹 50%，单次封顶 8）· 🕷️ 噬法幽魂（虚空净化：清空同房间玩家的【尘】/【护盾】/【蓄闪】/【白】，不造成伤害，极度怕近战、会一直后退）。第 1 层为兽人 / 咒术师，第 2 层起四种混出。
- **首领召唤**：首领每进一个阶段都会召唤精英（召唤物不掉落刻印），无尽模式每 3 层多召 1 只。
- **难度随人数与层数增长**：怪物血量 +80%/人、攻击 +30%/人；每下潜一层血量 +35%、攻击 +20%。
- **刻印（13 种基础 + 分支）**：类似遗物的被动/主动能力，可自选组合；①劫雷 / ③丰穰 / ⑦蹑景 / ⑧凌波两分支可叠加。
- **遗器（5 件）**：沧溟 / 七弦 / 斩月 / 掷星 / 忘川，各带独特主动技。首领击破后按层数概率掉落（第 1 层必掉、第 2 层 50%、第 3 层 30%，无尽模式每 3 层保底 100%、其余 10%），**遗器落在地上，需要走到该格拾取**（换层会清空未拾取的掉落物）。
- **附魔**：附在装备上，可随「给予」转移。
- **资产上限（地牢税）**：每人「背包物品 + 刻印 + 金币」总价值 ≤ 30 × 当前层数；点楼梯时全队检查，超载可用金币补足，补不齐则全员无法下楼。
- **首领锁血**：第 1 层 50% 一处，第 2 层起 66% / 33% 两处；锁血只提升 ATK 并召唤精英，**不再清空自身负面**（撕裂、点染等跨阶段保留）。首领带有【深渊同化】：一次攻击被减伤超过一半时，永久 ATK+2 / DEF+1（每回合 1 次）。首领免疫【蓝】【黄】与【戒律】，也免疫 ⑨b【撕裂】把 DEF 压到 0 以下造成的「禁足」（DEF 为负时增伤照常生效）；斩月【斩杀】/ 忘川【均分】同样会触发锁血。<br>- **荆棘反噬**：首领单次受到 ≥30 / 32 / 35（第 1/2/3 层）点伤害时，把超出部分按 50% / 60% / 70% **反弹为真实伤害，无上限**；噬盾吞噬者同样带反噬（≥15 起、50%、单次最多 8 点）。判定用「减免后、锁血前」的伤害，所以劫雷这类超大单段打首领会被反弹得很痛。
- **深渊侵蚀**：从**第 1 层**起就在无怪房间计数，阈值随层数收紧——**前两层 5 回合**、**第 3 层起 3 回合**，到点扣 5 点**真实伤害**（穿盾、清【尘】）。玩家卡会显示「⚠ 侵蚀 N/5（或 N/3）」徽章与状态行；**换到另一个房间**或**进入有怪的房间**都会把计时清零（换房时日志会提示「侵蚀重置」）。

完整规则见 **`abyss-echo-ringfall-rules.docx`**（游戏内「规则」面板也可随时查阅）。

## 更新日志

**v1.0**
- **炮台发射改成「地图瞄准」**：人类玩家发射不再弹一长串候选面板，而是进入瞄准模式——底部弹出**粉红色瞄准条**（与召唤物操控的紫色条区分开），位置与操作方式跟召唤物地图操控一致。箭矢：同房间所有存活单位描粉框，**点谁打谁**；TNT：**点哪格就以哪格为中心**，鼠标悬停时逐格预览 5×5 受击范围（中心格加深、超出房间的格子被裁掉，一眼看出能炸到谁）。条上有「取消瞄准」＝本次不发射、行动照常推进。
  - **两发箭矢仍是两次独立瞄准**：自动发射时每一发都会重新进瞄准条等你点人，不是选一次打两发
  - **AI 与主人阵亡代管完全不弹条**，照旧自动挑目标（TNT 按「命中敌人多、误伤少」评分）
  - **异常自愈**：炮台没了 / 弹药被清 / 阶段切走 / 已经轮到别人 / 弹出别的选择面板，瞄准条都会自动中止并回调取消，不会卡住自动连发；`machineAutoFire` 也加了回合归属校验，避免在别人回合里开枪
- **规则书第五章重排（怪物图鉴）**：原来「5.1 基础怪」把三只精英（渊火咒术师 / 噬盾吞噬者 / 噬法幽魂）混在普通怪表里，而「5.2 精英与首领」只列了兽人一只精英 + 五只 BOSS，分类是错的。现在按**普通怪（4 种）/ 精英怪（4 种）/ 首领（5 只）**三张表重排，每行统一给出 **HP / ATK / DEF / 射程 / 行动点 / 机制**六列，数值与游戏内图鉴（`MONSTER_DATA`）逐项对齐；首领的通用规则（锁血 / 深渊同化 / 荆棘反噬 / 首领免疫 / 阶段召唤 / 出场顺序）单独抽成六条要点，不再夹在怪物条目之间
- **顺带修正了三条与代码不符的描述**：地牢看守【战吼】原来写「召唤 2 只史莱姆」，实际代码只挂 2 回合【黄】、精英由 P2 通用召唤出 1 只咒术师；【引力黑洞】与【深渊处决】补上「【白】可免疫」；噬法幽魂改为「CD 3 循环清场 + 不攻击 + 2 格内后撤」，不再写成一次性开局技
- **召唤物改为每回合 2 点行动点**：一次行动不再直接结束召唤物回合——攻击 / 移动各消耗 1 点，每回合共 2 点，可以**连打两刀**、**打一刀再走一步**，或**连走两次**（每次最多 2 格）。人类操控时操控条与按钮面板都会显示「剩余 N 行动点」，做完一次行动立刻回到面板继续用剩下的点；点「待机 / 结束」或行动点耗尽才收尾。
  - **AI 同样拿 2 点**：没有 ⑩御灵、或把操控权交回「自动行动」时，召唤物按索敌逻辑连续执行到行动点耗尽（攻击前先判断射程，够不到就追一步再打）。
  - **巨兽例外不是改规则而是吃自己的硬直**：巨兽 `rest` 特性是「命中后休息 1 回合」，所以它打完第一刀就进入休息、剩余行动点作废——2 点对它实际是「走一步 + 打一刀」或「走两步」；游侠 / 幽灵 / 傀儡才真正拿到双份输出。
  - **蹑景（⑦）给的额外回合同样每组 2 点**，且人类玩家在额外回合里仍会重新进入操控面板，不会被强制自动索敌。
  - **敕罚（4b）仍然只结算一次**：中途换行动点不会重复触发，等整个召唤物回合结束（含休息硬直分支）才统一结算已挂上的禁行动。
- **目标池统一放宽（攻击/技能可选队友与召唤物）**：普攻、点染、裂帛、敕禁、七弦、斩月、忘川、掷星、沧溟、炮台、召唤物操控，全部把**同房间的队友与召唤物**纳入可选目标，用于互相解【蓝】/【白】、补刀、触发受击效果。地图点击也不再只认怪物——点队友或召唤物所在格即发起攻击（射程不够会提示先靠近）；召唤物操控时**敌方红框、友方黄框**，点谁打谁。AI 与自动索敌仍只打敌人，不会自残或误伤队友
- **炮台攻击管线重做（继承主人刻印）**：炮台发射不再是一句「弹药值 − DEF」的裸结算，而是走一条**独立管线**——攻击力 = 弹药基础值 + 残锋⑤（按主人已损 HP 增伤）+ 尘梦⑫b（主人每层【尘】+1 ATK），不吃武器加成；先判【劫雷①】暴击（×2~20），再过闪避判定（【蓄闪】能躲，**【白】挡不住炮台**——它是物理射击而非技能），命中后才结算伤害。命中后照常触发【裂帛⑨】+1 层【撕裂】与【点染⑪】上色。**反伤不弹给主人**（炮台是物，荆棘烧不到你）；主人阵亡后炮台仍会照常自动发射，只是不再继承残锋 / 尘梦加成
- **发射流程统一为一条执行器**：箭矢与 TNT 共用同一套 `doShoot` 结算。人类玩家先选目标、再弹【点染】选色面板（无 ⑪ 时不弹）；【黑】/【灰】只对单体生效，TNT 的范围弹不提供这两色。AI 代管时有【红】就上红、TNT 默认上红
- **箭矢目标扩容**：可以点友方（帮队友解【蓝】/【白】、补刀），也可以点自己（自残解控）——顺序固定为「敌方 → 友方 → 自己」，自己永远排最后并标注「（自己）」；AI 代管时仍只打敌人，不会自残。TNT 中心格按「命中敌人多、误伤少」排序
- **新增 2 只 BOSS + 1 种小怪**：
  - 🦋 **万母之巢**（BOSS 4，HP 180 / ATK 12 / DEF 6）：每回合开始【虫群孵化】最多 2 只巢穴爬虫（同房间上限 = 存活人数 ×2）；【精神控制】操纵同房间 HP 最高的召唤物调转枪口打主人（没有召唤物就改成 10 点精神撕裂）；锁血时【万物归巢】吞掉场上所有召唤物与爬虫，每吞 1 只**永久 ATK+1**，且不召唤精英
  - 👁 **千面之眼**（BOSS 5，HP 150 / ATK 15 / DEF 8 / 射程 3）：【千眼凝视】每回合最多承受 **3 + 存活人数 ×2** 次伤害判定，超出的攻击直接免疫；【弱点洞悉】把同房间敌人的 DEF 清零，持续到各自下个回合结束（【白】可免疫）；锁血时【千手之缚】全场挂【黄】并按存活人数凝护盾，也不召唤精英
  - 🐛 **巢穴爬虫**（HP 15 / ATK 4）：死亡时【自爆】对同房间其他单位造成 3 点真实伤害（可闪避），会**连锁引爆**同伴；用 `_exploded` 标记防重复触发
- **无尽模式 BOSS 轮换改为 5 个**：第 3 层仍是末环之影，第 4 层起按「末环之影 → 看守 → 领主 → 万母之巢 → 千面之眼」循环（原为 3 个一轮）；万母之巢无尽强化 +1 DEF/阶，千面之眼 +1 射程/阶，荆棘反噬阈值分别 34 / 35
- **召唤物改为「点地图」操控（⑩ 御灵）**：轮到你自己的召唤物行动时不再弹一长串按钮，而是直接进入**地图操控模式**——地图上亮起**紫色格**（本回合可达，最多 2 格）与 **红框敌人**（射程内可打），**点格子即移动、点敌人即攻击**；召唤物脚下标「▶操控」。操控条只留有 `待机 / 结束`、`自动行动`、`⚡蹑景`、`命中效果`，外加 `列表操作` 一键切回旧版按钮列表（小屏友好）。点射程外敌人会提示先靠近，点 3 格外或占用格会说明原因；出手或待机后操控条立刻收起，`G.sub` 一离开召唤物阶段也会自动清掉，不会残留拦截玩家点击
- **召唤物可手动操控（⑩ 御灵）**：持有 ⑩ 御灵时，轮到你自己的召唤物行动会弹出操控面板——`自动行动` / `攻击 <目标>`（带 HP、DEF、【尘】层数与预计伤害）/ `移动到 (x,y)`（本回合可达格）/ `待机`，还能勾选 `⚡蹑景` 换额外回合、更换命中附加的 ⑪/11b 颜色（【灰】可预设优先解除项）。没有 ⑩ 御灵时（含 AI）仍走原来的自动索敌，不弹面板
- **近战召唤物射程修复**：巨兽 / 幽灵的 `rng` 是 0（近战），但距离判定 `entDist` 里相邻就是 1，导致 `dist <= 0` 永远不成立——**此前近战召唤物只会「追击」到贴脸，却永远打不出那一击**。现已按「0 = 相邻 1 格」归一化，巨兽与幽灵能正常攻击
- **祭坛只认正中心 1 格**：以前点中心周围 3×3 都算「点祭坛」，误触频繁；现在祭坛正中心那 1 格**不可站立**（挡住去路），必须站在它上下左右的相邻格、再点中心格才弹交互面板。点中心格时若站得远，会自动走到最近的落脚格而不会踩上去；点其他格子则照常执行移动
- **祭坛绘制重做**：从单个 🌟 图标改成 **1 格发光底座**（紫框 + 半透明填充 + 辉光），用过的祭坛转为暗色残影（填充 5% / 描边 20% / 图标 30% 透明），一眼能分清「还能用」和「已经用过」
- **地上的掉落物终于能看见了**：首领/精英掉落的遗器与刻印、阵亡队友散落的背包，现在会在格子上画**金色虚线光环 + 物品图标**，同格多件时右下角显示 ×N 数量角标；以前这些只会进 `G.drops`，画面里完全看不出来
- **【白】文案改为「无法被技能选中」**：原描述写的是「无法被单体指向性技能选中」，但实际 AOE 技能（咒火洗礼 / 引力黑洞 / 战吼）与单体技能一律被挡，描述与实现不符；现在状态说明、点染日志、【灰】清除列表、阻挡提示统一为「无法被技能选中」，并保留具体技能名（如「无法被技能选中（碎裂重击）」）。物理普攻仍可命中且命中即解除【白】
- 内置**怪物图鉴**：顶部按钮一键查看普通 / 精英 / 首领的 HP、ATK、DEF、射程、行动数与技能说明
- **一键换武器**：点击自己卡片上的武器标签即可切换手持武器（不占行动点，会打断蓄力）
- **沧溟范围修正**：可分配目标改为「房间内 + 射程内」，射程下限 1 格；投出后以落点为圆心
- **状态拦截补全**：中【蓝】时点击怪物 / 点「攻击」均无法出手；中【黄】、被戒律封禁、DEF 为负时，点地图格、点门格、换房一律走不动（以前点地图可绕过）
