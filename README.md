# 深渊回响：末环
**Abyss Echo: RingFall** · v1.0

一个**单文件 HTML 地牢爬行游戏**——双击即玩，无需安装、无需联网、无任何依赖。
支持 1~4 人本地同屏（热座）合作闯关。

---

## 快速开始

1. 双击 **`index.html`**（或拖进任意现代浏览器：Chrome / Edge / Firefox / Safari）。
2. 选择模式（单人 / 多人）、人数与初始生命。
3. 点「开始冒险」。

> 全部逻辑与美术都在这一个 HTML 文件里，拷到 U 盘、发微信、传网盘都能直接玩。

### 在线游玩（GitHub Pages）

仓库根目录已经放好 `index.html`，进入 **Settings → Pages**，Source 选 `Deploy from a branch`、分支选 `main` / 目录 `/ (root)`，保存后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可在线玩。

### 局域网联机

最多 4 人各自用电脑 / 手机浏览器联机下潜，同在一个局域网即可，不用传文件、不用公网 IP：

1. **房主**：在一台电脑上执行
   ```bash
   npm install ws
   node server.js        # 默认端口 8080，可用 PORT=xxxx 换端口
   ```
   然后按提示打开 `http://localhost:8080/`（服务同时会静态托管游戏本体，队友不需要另拿文件）。开局面板点「**作为房主开房**」，回车确认地址即可。
2. **队友**：浏览器打开房主屏幕上显示的地址（如 `http://192.168.1.10:8080/`），点「**加入房间…**」，自动领取一个玩家位（2 号位起依次分配）。
3. 房主看到「玩家 2 远程玩家」占位后，点「开始游戏」。之后所有人看到同一张地图、同一份日志；**轮到谁，谁的屏幕才能操作**，其他人面板上盖着「等待 玩家 X 操作…」。

联机要点：

- 游戏逻辑全部跑在房主机上，客户端只负责显示与上报操作——没有状态分歧，断线也不会污染对局；
- 移动 / 攻击 / 开箱 / 给予 / 商店 / 刻印自选 / 召唤物地图操控等操作都能远程完成；地图点击按**格子坐标**转达，两端窗口大小不同也不影响；
- 房主中途关服或掉线，客户端会收到提示；队友掉线后其座位自动释放，房主可继续带剩余玩家打完；
- 不经静态托管也可以玩：房主直接双击 `index.html`，开房时地址填 `ws://本机IP:8080`，队友双击同一份 `index.html` 加入（需要先把文件发给队友）。
- `abyss-echo-ringfall-rules.docx` 是纯规则书，联机用不到，可不下发。

## 一、玩法目标

探索随机生成的地牢，逐层下潜，击败每层首领。**主线 5 层**，每层一只专属首领：

| 层 | 首领 | HP | ATK | DEF | 备注 |
|---|---|---|---|---|---|
| 1 | 👑 地牢看守 | 80 | 8 | 3 | 2 段血 |
| 2 | 😈 深渊领主 | 162 | 12 | 5 | 3 段血起 |
| 3 | 👾 末环之影 | 306 | 16 | 6 | 3 行动点 |
| 4 | 🦋 万母之巢 | 368 | 19 | 6 | 虫群 + 精神控制 + 织茧 |
| 5 | 👁 千面之眼 | 360 | 27 | 8 | 终局 + 千眼吞噬 |

表中数值为单人、对应层数的实际生成值（含难度缩放）。击败第 5 层首领后可选择**带着荣誉通关**，或**继续下潜**进入无尽模式：第 6 层起五只首领按同样顺序循环，并继续叠加【深渊·N阶】强化（每 5 层一阶）。

## 二、基本操作

| 操作 | 方式 |
|---|---|
| 移动 | 点击地图上的发光格（每回合最多 2 格；持 ⑥b 天工则同房间任意格都能一次走到，开箱 / 拾取 / 祭坛 / 商店交互也无需走近） |
| 攻击 | 点击射程内的敌人或队友（列表里队友标注「（队友）」），也可用「攻击」按钮 |
| 切换武器 | 点击自己卡片上的武器标签（青框可点，仅自己回合且有行动点时）——不占行动点，但会打断蓄力 |
| 开箱 / 给予 / 丢弃 / 道具 / 附魔 | 左侧行动按钮 |
| 刻印主动技 | 「刻印技能」按钮打开二级菜单（蹑景 / 裂帛 / 残锋 / 点染 / 御灵召唤 / 蓄闪 / 敕禁 / 天工），当前不可用的项置灰；点进某一项后的子面板，**「取消」只退回这份菜单**，再点一次「取消」或按 `Esc` 才彻底退出。其中**裂帛、御灵召唤在额外回合（含插队回合）里也能发动**，其余限主要行动回合 |
| 楼梯 | 走到楼梯相邻格后点击楼梯格 |
| 结束回合 | 「结束回合」按钮 |
| 怪物图鉴 | 顶部「📖 怪物图鉴」，查看全部怪物属性与技能（Esc 关闭） |

每人每回合 **2 点行动点**：移动、攻击、开箱、给予、道具各消耗 1 点；丢弃、附魔（限 1 次）、商店交易不占行动点。打开选择面板时按钮网格会让位，面板关闭后复原。

## 三、回合与行动点

- **回合顺序**：玩家全动 → 怪物全动，每轮按队列推进；玩家死亡但场上仍有自己的召唤物时，依然占据回合位。
- **额外回合**（⑦蹑景 / 掷星质数）：作为**顺延额度**记账，在本回合主要行动结束时立刻兑现，一回合内可多次行动。
- **怪物阵亡不吞回合**：怪物在放技能的中途被荆棘反伤、AOE 或炮台打死，同样会立刻交还回合控制权并推进队列，不会卡住；脱离队列的过期回调也不会强插别人的回合。
- **插队**（⑧b 凌波）：行动点一结算就立刻插入——被打断者**保留剩余行动点**，插队回合结束后由它接着行动（怪物、队友、AI 同规则）；若它行动点已耗尽或已阵亡，则照原流程收尾后再推进队列。插队回合内不会嵌套打断。**插入的回合数 N = ⑧a 凌波·分支①的层数**（每层 30% 闪避，也就每层 1 个额外回合），⑧b 自身只是开关、多叠无收益；⑧a 为 0 层时⑧b 不触发。
- **召唤物也能插队**：⑩御灵共享给召唤物的 ⑧b 闪避成功时，同样**立即插入**（打断当前行动者，按 2 点行动点跑完再交还）；召唤物行动阶段（`召唤物回合 / 召唤物额外回合`）里玩家按钮与地图操作全部锁住，避免误操作。

## 四、战斗

- **伤害**：`ATK − DEF`，低于 0 则无伤害（但记 1 次受击，可触发受击效果）。
- **暴击**：只有攻击管线可以暴击（①劫雷 ×2~20）——玩家普攻、召唤物攻击与炮台射击共用这一判定；遗器技能、技能伤害与撕裂不暴击。
- **目标池**：所有攻击与技能都可选**同房间的队友与召唤物**，用于互相解【蓝】/【白】、补刀、触发受击效果；伤害真实生效，小心打死自己人。点地图上的队友 / 召唤物 / 自己所在格同样算攻击。AI 与自动索敌只打敌人。
- **状态**：
  - 【蓝】无法攻击，受伤即解除（自己人打一下也算）。
  - 【白】无法被技能选中（单体与 AOE 一律挡），物理普攻仍可命中，命中即解除。
  - 【黄】无法移动；【黑】/【灰】用于点染与解控。
- **命中附加**：⑨裂帛 +1 层【撕裂】、⑪点染上色，只有物理攻击管线（普攻 / 召唤物 / 炮台）会触发。

## 五、地牢结构

- **房间**：5×4 网格上随机生长 8~16 个房间——战斗 / 精英（每层保底 1 个）/ 宝藏 / 商店（每层保底 1 个）/ 祭坛 / 首领。入口房固定有「人数 + 1」个补给宝箱（上限 6）。
- **祭坛**：只认正中心 1 格，且该格不可站立——必须站在上下左右的相邻格再点中心格才弹交互面板（持 ⑥b 天工则站房间任意位置点中心格即可），用过的祭坛变暗色残影。
- **掉落物**：首领掉落的遗器、精英掉落的刻印、阵亡队友散落的背包都落在地上，格子上画金色虚线光环 + 物品图标，同格多件显示 ×N；**需要走到该格拾取**（持 ⑥b 天工可点击该格隔空拾取，消耗 1 行动点），换层会清空未拾取的掉落物。点楼梯时会先代为拾取楼梯格上的掉落物再下楼。
- **深渊侵蚀**：无怪房间每回合 +1 计数，**前两层阈值 5、第 3 层起 3**；到点扣 5 点真实伤害（穿盾、清【尘】、触发忘川判定）。换房间、进入有怪的房间、下潜新层都会清零，不跨层累计。玩家卡显示「⚠ 侵蚀 n/3」倒计时。
- **资产上限（地牢税）**：每人「背包 + 刻印 + 金币」总价值 ≤ 30 × 当前层数；点楼梯时全队检查，超载可用金币补足，补不齐则全员无法下楼。
- **难度缩放**：怪物血量 +80% / 人、攻击 +30% / 人；每下潜一层血量 +35%、攻击 +20%，并增加护卫数量。

## 六、怪物

- **普通怪（4 种）**：🟢 史莱姆（凝胶）· 🏹 哥布林弓手（破魔穿透箭）· 🐺 暗影狼（撕裂）· 🐛 巢穴爬虫（死亡自爆，可连锁引爆）。
- **精英怪（4 种）**：👹 兽人（狂怒 / 碎裂重击）· 🔮 渊火咒术师（咒火洗礼 + 后跳 + 受击瞬移）· 🩸 噬盾吞噬者（截胡护盾 / 碾碎【尘】/ 荆棘反噬 ≥15 反弹 50%，单次封顶 8）· 🕷️ 噬法幽魂（虚空净化：清空同房间玩家的【尘】/【护盾】/【蓄闪】/【白】，不造成伤害，极度怕近战、会一直后退）。
- **精英出场**：第 1 层从兽人 / 渊火咒术师里二选一，第 2 层起四种混出。
- **首领机制**：
  - **锁血**：第 1 层 50% 一处，第 2 层起 66% / 33% 两处。锁血只提升 ATK 并召唤精英，**不清空自身负面**（撕裂、点染跨阶段保留）；斩月【斩杀】/ 忘川【均分】同样会触发锁血。
  - **深渊同化**：一次攻击被减伤超过一半时，永久 ATK+2 / DEF+1（每回合 1 次）。
  - **荆棘反噬**：单次受到 ≥30 / 32 / 35 / 34 / 35（看守 / 领主 / 末环 / 万母 / 千面）点伤害时，把超出部分按 50% / 60% / 70% / 60% / 70% **反弹为真实伤害，无上限**。判定用「减免后、锁血前」的伤害。
  - **免疫**：【蓝】【黄】【戒律】，以及 ⑨b 把 DEF 压到 0 以下的「禁足」；DEF 为负时增伤照常生效。
  - **阶段召唤**：每次进入新阶段都会撕裂空间召唤精英（召唤物不掉刻印、不给金币）。基础数量按首领与阶段固定（看守 1 只 / 领主 1 只 / 末环 2 只），**每多 1 名玩家再加 1 只**（2 人局 +1、3 人局 +2），层数越高召得越多（6~10 层 +1、11~15 层 +2）；末环之影第 3 阶段改召【噬法幽魂】。万母之巢与千面之眼不召精英，改触发各自的锁血技。
  - **专属首领**：🦋 万母之巢每回合孵化巢穴爬虫、操纵召唤物反打主人、锁血时【织茧】织出【深渊之茧】（3 回合内需打断 10 + 人数×8 次，破茧则自身 DEF 归零 2 回合 + 全队回血 10，未破则强制处决全场）；👁 千面之眼每回合限伤 `3 + 存活人数 ×2` 次、把同房间敌人 DEF 清零、【白】可免疫、锁血时全场挂【黄】并【千眼吞噬】随机吞掉每人 1 件遗器（击败后吐出）。

## 七、深渊模式（第 6 层起，每 5 层一阶）

第 1~5 层是常规层，首领不带加成。进入无尽模式后（第 6 层起）**每 5 层提升一阶**：

| 层 | 6~10 | 11~15 | 16~20 | 21~25 |
|---|---|---|---|---|
| 阶数 | 1 阶 | 2 阶 | 3 阶 | 4 阶 |

每阶：**血量 +30%、攻击 +15%**，并按首领追加特色强化——看守 +3 DEF/阶、深渊领主 +1 射程、末环之影黑洞 CD 缩短（最低 1）、万母之巢 +1 DEF/阶、千面之眼 +1 射程/阶。阶段召唤的额外护卫与阶数同步（6~10 层 +1、11~15 层 +2）。末环之影的【深渊处决】登场后**先冷却 1 个自己的回合**（首回合不会处决），之后使用有独立的 **CD 2**（不随阶数缩短、与引力黑洞分开算），不会再在同一回合里连斩。

首领按「看守 → 领主 → 末环 → 万母 → 千面」循环，第 6 层从看守重新开始。

## 八、召唤物

- **行动点**：每回合 2 点，攻击 / 移动各 1 点（移动每次最多 2 格；主人同时持 ⑩御灵与 ⑥b 天工时，召唤物也能到同房间任意格）——可以连打两刀、打一刀再走一步、或连走两次，行动点耗尽或选择待机才收尾。
- **操控（⑩御灵）**：轮到自己召唤物时进入**地图操控模式**——紫格可达、红框敌人可打，**点格子即移动、点敌人即攻击**；操控条保留 `待机 / 结束`、`自动行动`、`⚡蹑景`、`命中效果`、`列表操作`（切回按钮列表）。点射程外敌人会提示先靠近。没有 ⑩ 御灵（含 AI）走自动索敌。
- **额外回合（⑧b 凌波）**：与玩家同规则——**闪避成功的瞬间就插队**，打断当前行动者（怪物 / 队友）先打这一轮，打完再把回合交还给它继续（它剩余的行动点不丢）。插入的回合数同样**取 ⑧a 的层数**（主人经 ⑩御灵 共享给召唤物），逐次执行、每次一个完整回合。
- **蹑景（⑦）仍然顺延**：召唤物在回合内声明蹑景，额外回合接在**自己这一轮之后**连续执行，不插别人的队——和玩家的蹑景完全一致。
- **每回合 2 点**：无论是正式回合还是插队回合，按**一整个回合**结算，即 2 点行动点——玩家操控与 AI 自动执行规则一致。
- **AI 同样 2 点**：没有 ⑩ 御灵或交回「自动行动」时，按索敌逻辑连续执行到行动点耗尽（攻击前先判断射程，够不到就追一步再打）。
- **巨兽的硬直**：巨兽「命中后休息 1 回合」，打完第一刀就进入休息、剩余行动点作废——2 点对它实际是「走一步 + 打一刀」或「走两步」。
- **近战射程**：巨兽 / 幽灵的射程写作 0，按「相邻 1 格」处理，能正常攻击。
- **敕罚（4b）**：只在召唤物回合结束时统一结算一次，中途消耗行动点不会重复触发。
- **阵亡**：召唤物被反伤打死时，剩余行动点作废、操控条立刻收起；若它是全场最后一个存活单位，立即判负。

## 九、炮台

- **发射**：箭矢 8 ATK 单体；TNT 16 ATK，自选一格为中心造成 5×5 范围爆炸，**范围内的所有实体（含玩家、队友、召唤物、怪物）都会受伤**。
- **地图瞄准**：人类玩家发射时进入瞄准——底部弹出粉红瞄准条。箭矢模式点哪个实体就打哪个（同房间所有存活单位描粉框，含队友、召唤物与自己）；TNT 模式点哪格就以哪格为中心，悬停时逐格预览受击范围。两发箭矢是两次独立瞄准。「取消瞄准」＝本次不发射、行动照常推进。
- **伤害管线**：攻击力 = 弹药基础值 + ⑤残锋（按主人已损 HP 增伤）+ ⑫b 尘梦（主人每层【尘】+1 ATK），不吃武器加成；先判 ①劫雷 暴击，再过闪避（**【白】挡不住炮台**——它是物理射击），命中后触发 ⑨裂帛 + ⑪点染。
- **反伤**：不弹给主人（炮台是物）。主人阵亡后炮台仍会自动发射，也不会继承残锋 / 尘梦。
- **异常自愈**：炮台没了 / 弹药被清 / 阶段切走 / 轮到别人 / 弹出别的面板，瞄准条自动中止并回调取消，不会卡住连发。

## 十、刻印、遗器与附魔

- **刻印（13 种基础 + 分支）**：类似遗物的被动 / 主动能力，可自选组合；①劫雷 / ③丰穰 / ⑦蹑景 / ⑧凌波两支可叠加。
- **遗器（5 件）**：沧溟（范围分配）/ 七弦（七连射）/ 斩月（斩杀）/ 掷星（随机质数奖励）/ 忘川（不死均分），各带独特主动技。首领击破后按层数掉落：第 1 层必掉、第 2 层 50%、第 3~5 层 30%、第 6 层起每 3 层保底 100%（其余 10%）。遗器落在地上，需走到该格拾取。
- **附魔**：附在装备上，可随「给予」转移；每回合限 1 次，不占行动点。

## 十一、界面与适配

- **桌面（>900px）**：整页锁死一屏不滚动——左侧地图吃掉剩余高度，右侧玩家列表独立滚动、日志固定底栏；按钮区按内容自适应（176~220px，矮屏 160px），装不下时自行滚动，「规则 / 强制结束 / 返回主页面」吸底常驻。
- **手机（≤900px）**：整页可滚动，顶栏 46px 吸顶，**地图吸在顶栏下方、高度 45vh**，按钮四列，玩家卡横向滑动（**物品 / 刻印 / 状态三行在手机上同样显示**，卡片高度约 130~155px），日志落到页面底部；≤420px 再压一档字号，360×640 无横向溢出，面板「取消」仍在视口内。
- **按钮配色**：行动按钮、系统按钮、面板选项共用一套色板（`--btn-*`）——可用＝半透明白底＋淡蓝边框＋白字，悬停＝青绿，不可用＝虚线＋灰字；只有危险操作（强制结束、确认丢弃）才用粉红。
- **房间自适应铺满**：格子边长按房间尺寸自适应：`tile = min((画布宽 − 小地图位)/房间宽, (画布高 − 顶栏)/房间高)`，5×5 与 9×9 都铺满同一块区域（约 480×480 逻辑像素），小地图竖版贴在右侧（桌面 200×300，手机 140×200），房间与小地图不重叠。
- **地图点击**：画布按 `object-fit: contain` 等比内缩，坐标换算带居中偏移，`tileAtEvent` 与绘制共用 `roomFrame()`，点在留白区也不会错位（桌面、手机、召唤物操控、炮台瞄准同一套换算）。
- **强制结束**：直接判为**全军覆没**（不评选胜者、不计排名），用于卡住或想重开时立刻收场。
- **面板可见性**：`#choice` / 召唤物操控条 / 炮台瞄准条一出现就自动滚进按钮区视野，关闭后滚回原位置。
